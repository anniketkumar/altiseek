# Documentation index

Start with the [write-up](paper.md). The design, data contracts and decision log (D1–D62) are in
[CLAUDE.md](../CLAUDE.md). Each milestone folder holds that stage's protocols (frozen before any
test run), generated results, and an acceptance review. Generated result files are byte-preserved
copies of their reports; do not edit them by hand.

| Document | What it covers |
|---|---|
| [paper.md](paper.md) | Paper-style write-up: method, RQ1–RQ3 results, limitations |
| [results.md](results.md) | M1–M5 results (detector, levels, fidelity, cache) and the figure index |
| [figures/](figures/) | Every figure: numeric plots only, regenerated by scripts |
