## Owner's working rules

- **Commit and push** finished, tested increments to `main` at
  https://github.com/anniketkumar/altiseek. Stage explicit file lists.
- **No AI attribution anywhere.** Commits and PRs carry no `Co-Authored-By` lines and no
  "generated by" notes.
- **Never commit dataset imagery** (CLAUDE.md §2): crops, patches, rendered worlds or views,
  caches, checkpoints or demo videos. `data/` and `runs/` are gitignored. Plots of numbers may
  go in `docs/figures/`.
- **Log deviations.** When the implementation must deviate from CLAUDE.md, update the section and
  add a Decision Log row (§24) in the same commit. The next free ID is **D63**.
- **Tell the owner** where their input is needed and give factual progress updates. Background
  jobs are not alerts; do not promise unsolicited notifications.
- **Test before committing.** `uv run pytest` runs the tests plus ruff format and lint (391 pass
  at D62).

## Layout

See CLAUDE.md §6. In brief:
- `src/altiseek/` is the library;
- `scripts/<stage>/` holds the CLI entry points, run from the repository root;
- `configs/eval/` holds frozen protocols, which are never edited;
- `docs/` holds per-milestone protocols, results and reviews.
