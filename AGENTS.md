## Layout

See CLAUDE.md §6. In brief:
- `src/altiseek/` is the library;
- `scripts/<stage>/` holds the CLI entry points, run from the repository root;
- `configs/eval/` holds frozen protocols, which are never edited;
- `docs/` holds per-milestone protocols, results and reviews.
